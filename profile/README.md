## <a id="中文"></a>中文

`ai-workspace-xstream` 是面向全球 AI 服务访问与私有网络互联的组织。我们把海外 AI 服务加速、桌面与移动端客户端、节点管理、隧道接入和安全访问整合到同一个产品体系里，让跨网络、跨设备的连接体验更稳、更快、更易管理。

### 线上运行

这不是演示页，而是实际在线运行的服务。

- 真实生产环境持续提供服务
- 支持 GitHub OAuth 登录
- 支持 Google OAuth 登录
- 面向实际用户的节点、隧道与账号体系

### 我们在做什么

- 构建面向海外 AI 服务的加速与接入能力
- 提供桌面端、移动端和服务端的一体化客户端体验
- 支持私有网络互联、隧道访问和节点配置管理
- 让网络接入、诊断和配置分发保持可视化、可控、可追踪

### XStream

我们的产品主页以 `XStream` 为核心，强调“全平台海外 AI 服务加速与私有网络互联”：

- `Desktop`：macOS / Windows / Linux 客户端
- `iOS`：移动端使用与系统级能力接入
- `Secure Browser Access`：安全浏览器访问与后续扩展
- `Node Management`：节点、策略与隧道配置管理

### 核心能力

- 海外 AI 服务加速
- 私有网络互联与安全接入
- 节点管理与策略控制
- 隧道诊断与状态可视化
- 桌面端与移动端一致性体验

## <a id="english"></a>English

`ai-workspace-xstream` is the organization focused on global AI service acceleration and private network connectivity. We combine overseas AI access acceleration, desktop and mobile clients, node management, tunnel connectivity, and secure access into one product system so cross-network, cross-device experiences stay stable, fast, and manageable.

### Live service

This is a live production service, not a demo.

- Running continuously in a real production environment
- Supports GitHub OAuth login
- Supports Google OAuth login
- Built for real users, nodes, tunnels, and account workflows

### What we do

- Build acceleration and access capabilities for overseas AI services
- Provide a unified client experience across desktop, mobile, and backend services
- Support private network interconnects, tunnel access, and node configuration management
- Keep networking, diagnostics, and configuration delivery visible, controlled, and traceable

### XStream

Our product homepage centers on `XStream`, with a clear focus on global AI service acceleration and private network connectivity:

- `Desktop` for macOS / Windows / Linux
- `iOS` for mobile use and system-level integration
- `Secure Browser Access` for secure web access and future expansion
- `Node Management` for nodes, policies, and tunnel configuration

### Core capabilities

- Global AI service acceleration
- Private network connectivity and secure access
- Node management and policy control
- Tunnel diagnostics and status visibility
- Consistent desktop and mobile experience
